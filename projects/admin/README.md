# 🛡️ Enterprise Admin Dashboard Workspace (`projects/admin/`)

> **This directory is reserved as the home for your enterprise backoffice portals, internal analytics dashboards, customer support tools, and Role-Based Access Control (RBAC) suites.**

---

## 🌐 Universal Any-Stack Ready
You can build or import **ANY admin panel or dashboard software** here:
* **React / Next.js Admin**: *React Admin, Refine, Next.js Custom Backoffice, Tremor Dashboard*
* **Vue & Nuxt Admin**: *Nuxt Admin suites, Vuetify Admin, Quasar Backoffice*
* **Traditional Backend Dashboards**: *Django Admin, Laravel Nova, Ruby ActiveAdmin, ASP.NET Blazor*
* **Data Grids & Visuals**: *TanStack Table v8, AG-Grid, Highcharts, ECharts, Chart.js*

---

## 🚀 How to Add Your Code
1. **Clone an Existing Admin Panel**: Place your existing admin codebase files directly into this directory.
2. **Start Greenfield**: Instantiate your dashboard scaffold right here.

---

## 🤖 How `.brain/` Automatically Powers This Workspace
Whenever your AI assistant touches this directory:
1. It reads **[`../../.brain/memory/admin-memory.md`](../../.brain/memory/admin-memory.md)** to adhere to dual-layer RBAC authentication matrices and server-side cursor pagination standards.
2. Every time a new permission tier, KPI metric chart, or data grid table is added, the AI **autonomously updates** `admin-memory.md`, ensuring total security immunity and minimal token overhead!
