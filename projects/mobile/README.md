# 📱 Mobile Application Workspace (`projects/mobile/`)

> **This directory is the dedicated home for your native and cross-platform mobile app repositories, offline sync engines, and native device integration layers.**

---

## 🌐 Universal Any-Stack Ready
Our v3.0 AI Developer Brain is fluent across **ALL mobile development languages and frameworks**:
* **Flutter** (*Dart 3, Bloc, Riverpod, Isolate workers*)
* **React Native** (*TypeScript, Expo, WatermelonDB, Reanimated 3*)
* **Native Android** (*Kotlin, Jetpack Compose, Room DB*)
* **Native iOS** (*Swift, SwiftUI, CoreData / SwiftData*)
* **Cross-Platform**: *Kotlin Multiplatform (KMP), Ionic, Capacitor, .NET MAUI*

---

## 🚀 How to Add Your Code
1. **Clone your mobile app repository** directly into this folder.
2. **Start Greenfield**: Execute your initialization commands (*e.g., `flutter create .` or `npx create-expo-app .`*) here.

---

## 🤖 How `.brain/` Automatically Powers This Workspace
When an autonomous AI agent develops mobile features:
1. It consults **[`../../.brain/memory/mobile-memory.md`](../../.brain/memory/mobile-memory.md)** and **[`../../.brain/standards/mobile-and-offline.md`](../../.brain/standards/mobile-and-offline.md)** to implement butter-smooth 60/120 FPS UI workers, hardware keychain vaults, and offline SQLite synchronization outbox queues.
2. On every schema alteration or native bridge addition, the AI **autonomously records** the updates inside `mobile-memory.md`!
