# ⚙️ Backend Application Workspace (`projects/backend/`)

> **This directory is the dedicated home for your backend API services, microservices, cloud functions, and database schemas.**

---

## 🌐 Universal Any-Stack Ready
You can clone, initialize, or develop **ANY backend technology stack** directly inside this directory. Our v3.0 AI Developer Brain seamlessly adapts to:
* **Node.js & TypeScript** (*NestJS, Express, Fastify, Hono*)
* **Python** (*FastAPI, Django, Flask, Litestar*)
* **Go (Golang)** (*Gin, Fiber, Echo, standard net/http*)
* **Rust** (*Actix Web, Axum, Rocket*)
* **Java / Kotlin** (*Spring Boot, Quarkus, Micronaut*)
* **C# .NET / PHP Laravel / Ruby on Rails**

---

## 🚀 How to Add Your Code
1. **Clone an Existing Repo**: Run your `git clone <your-repo-url> .` directly inside this folder.
2. **Start Greenfield**: Run your framework initialization CLI (*e.g., `npm i -g @nestjs/cli && nest new .` or `pip install fastapi uvicorn`*) right here.

---

## 🤖 How `.brain/` Automatically Powers This Workspace
Whenever you assign a task to your AI assistant (*Cursor, Windsurf, Claude, Gemini, Antigravity*):
1. The AI reads **[`../../.brain/memory/backend-memory.md`](../../.brain/memory/backend-memory.md)** and **[`../../.brain/standards/backend-and-cloud.md`](../../.brain/standards/backend-and-cloud.md)** to generate secure, layered, production-grade APIs.
2. On every code modification, database migration, or new endpoint created in this folder, the AI **autonomously updates** `backend-memory.md` so your project intelligence is always synchronized with minimum token consumption!
