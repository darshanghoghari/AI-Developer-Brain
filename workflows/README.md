# 🔄 Step-by-Step AI Execution Protocols (`/workflows/`)

> **Deterministic Operational Procedures Guiding AI Agents Through Complex Software Tasks without Human Intervention.**

---

## 🎯 Core Objectives & Scope

Workflows in this directory transform complex engineering endeavors into rigorous **Step-by-Step State Machines**. When an AI coding assistant (Antigravity, Claude Code, Cursor, Copilot) executes a workflow from this directory, it follows explicit pre-flight check criteria, verification commands, and non-destructive git disciplines.

---

## 📋 Initial Available Workflows

* **Feature Implementation Lifecycle**: Defines how an agent inspects requirements, updates type schemas, drafts TDD unit test shells, and iteratively generates functional implementation code.
* **Pull Request Code Audit & Quality Review Checklist**: Establishes objective code reviewing rubrics for AI evaluation of diffs (Checking for missing error wrappers, unprotected API parameters, or console log leftover junk).
* **TDD Bug Resolution & Regression Squasher**: Guides an agent through reproducing an issue via tests, applying minimal patching, and verifying overall build integrity.

---

## 🛠️ Creating New Workflows
When designing new workflows for AI execution, base your structure on `../templates/workflow-template.md` to ensure standardized execution protocols across diverse LLM tooling.
