# 🤖 Reusable AI Prompt Library (`/prompts/`)

> **Curated Zero-Shot, Chain-of-Thought, and Meta-Prompts for Architecture Assessment, Debugging, and System Optimization.**

---

## 🎯 Core Objectives & Scope

This folder acts as an actionable prompt inventory designed to prime conversational LLMs and autonomous agents with high-precision task execution parameters. Prompts within this library bypass repetitive instruction setups and command deterministic engineering outputs.

---

## 📂 Prompt Categories & Integration

1. **Architecture & System Design Prompts (`system-design/`)**: Prompts that challenge an AI to design scalable distributed architectures, evaluate database normalization models, or debate microservices vs. monolithic trade-offs.
2. **Security Vulnerability Auditing Prompts (`security-auditor/`)**: Specialized directives instructing an AI assistant to inspect code snippets exclusively through the lens of an adversarial OWASP penetration tester and remediation engineer.
3. **Refactoring & Clean Code Prompts (`refactor/`)**: Structured instructions designed to take chaotic, high-complexity legacy code functions and decompose them into clean, modular, and type-safe components matching our `AGENTS.md` universal rules.
4. **Customizing & Contributing**: Every new prompt template stored here must follow unambiguous token usage guidelines, clear placeholder variables (e.g., `{{TARGET_LANGUAGE}}`, `{{DATABASE_SCHEMA}}`), and explicit evaluation criteria.
